System Software & Architecture

System software provides the essential functions for the computer to operate and serves as a platform for application software.

Operating Systems (Kernels)

The core software that manages hardware resources (CPU, Memory, I/O).

  • Monolithic Kernels: Linux, FreeBSD, OpenBSD.
  • Microkernels: QNX (Automotive), Minix, Zircon.
  • Hybrid Kernels: Windows NT, macOS (XNU).
Virtualization & Hypervisors

Software that allows multiple operating systems to run on a single physical machine.

  • Type-1 (Bare Metal): VMware ESXi, Microsoft Hyper-V, Xen.
  • Type-2 (Hosted): Oracle VirtualBox, VMware Workstation.
  • OS-Level: Docker, Podman, Linux Containers (LXC).

Programming Ecosystems

Low-Level & System Languages

Focused on memory management and high performance.

  • C/C++: The foundation of all modern OS and high-end games.
  • Rust: Modern alternative focusing on memory safety.
  • Go (Golang): Developed by Google for massive cloud concurrency.
High-Level & Scripting

Abstracted languages for rapid application development.

  • Python: The leading choice for AI, automation, and science.
  • Java: Enterprise standard using the JVM (Java Virtual Machine).
  • TypeScript/JS: The undisputed language of the modern web.
Compilers & Build Tools

Software that translates source code into machine instructions.

  • GCC / Clang: Industry-standard C/C++ compilers.
  • Maven / Gradle: Build automation for Java ecosystems.
  • LLVM: A collection of modular compiler technologies.

Web & Cloud Platforms

Software that powers the modern internet and distributed computing architectures.

Backend Frameworks

Server-side logic and API management software.

  • Node.js (Express/Nest): Scalable JavaScript environments.
  • Django/FastAPI: Python frameworks for secure, rapid APIs.
  • Spring Boot: Robust Java framework for microservices.
Cloud Management & DevOps

Software for orchestrating thousands of virtual servers.

  • Kubernetes (K8s): Container orchestration at scale.
  • Terraform: Infrastructure as Code (IaC) management.
  • Jenkins / GitHub Actions: CI/CD automation software.

Database Management (DBMS)

Relational Databases (SQL)

Strictly structured data using tables and ACID compliance.

  • PostgreSQL: The most advanced open-source DB.
  • MySQL / MariaDB: Popular for web-based applications.
  • Oracle DB / MSSQL: Enterprise-grade proprietary systems.
NoSQL & specialized Storage

Flexible schemas for big data and real-time scaling.

  • MongoDB: Document-based storage.
  • Redis: High-speed in-memory key-value store.
  • Elasticsearch: Distributed search and analytics engine.

Artificial Intelligence & Data Science

Machine Learning Frameworks

Libraries used to build and train neural networks.

  • PyTorch: Developed by Meta, favored by researchers.
  • TensorFlow: Google's flagship ML ecosystem.
  • Scikit-learn: Classic machine learning tools for Python.
LLM & Generative AI

Models capable of processing and generating human-like data.

  • GPT Models: OpenAI's multi-modal intelligence.
  • Llama: Open-weights models by Meta.
  • Claude: Anthropic's safety-focused AI models.

Creative & Production Software

Visual Design & UI/UX
  • Adobe Creative Cloud: Photoshop, Illustrator, InDesign.
  • Figma: Industry standard for collaborative interface design.
  • Affinity Suite: Professional-grade lightweight design tools.
3D, VFX & Game Engines
  • Unreal Engine: High-fidelity real-time 3D rendering.
  • Blender: The world's leading open-source 3D suite.
  • Unity: Cross-platform engine for mobile and 2D/3D games.

Cybersecurity & Networking Software

Penetration Testing & Analysis
  • Wireshark: Network protocol analyzer and packet sniffer.
  • Metasploit: Framework for developing and executing exploit code.
  • Burp Suite: Comprehensive platform for web app security testing.
Identity & Encryption
  • HashiCorp Vault: Secure secret management software.
  • VeraCrypt: Open-source disk encryption software.
  • Bitwarden: Open-source password management.
